# Thomso

React page for Thomso, the cultural fest of IIT Roorkee. This project is an interview exercise.

## How to run

```bash
git clone https://github.com/LifeAyush/thomso-landing.git
cd thomso-landing
npm install
npm start
```

The development server runs at [http://localhost:3000](http://localhost:3000).
